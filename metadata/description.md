# Satori — Internal Affairs — description

An interactive medical-mystery simulator built as a working demonstration of AI governance — players diagnose under pressure, and error can be fatal.

Version one was a single prompt: present a case, let the model improvise. It broke fast — facts invented, diagnoses changed mid-game, contradictions everywhere. Satori's answer is to separate generation, execution, and narration into three layers: an LLM pipeline grounded in medical research generates cases from structured seeds and freezes them as immutable, schema-validated JSON; a deterministic engine runs gameplay — actions, time, vitals, deterioration, outcomes — with no runtime generation; and a tightly bounded final LLM layer adds narrative color that describes what happens but never decides what is medically true. Four boundaries — Freeze, Truth, Narration, Provider — enforce the separations, so gameplay stays deterministic and auditable even though the cases are AI-authored. The toy version is a medical game built for one teenager who lives with epilepsy from a TBI and wanted to understand the medicine; the general argument is for every regulated domain, where the boundaries between generation, execution, and narration determine what AI is allowed to do and what humans evaluate. Its paired companion is Glassroom — same architectural principle, inverse direction, built for the same daughter.

Python with Pydantic and a SvelteKit + TypeScript frontend, structured as a four-package monorepo — Anamnesis (design-time case generation), Satori (the deterministic engine), an LLM client abstraction, and Internal Affairs (the frontend). In development.
